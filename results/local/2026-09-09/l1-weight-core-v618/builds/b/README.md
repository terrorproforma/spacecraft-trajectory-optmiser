# Reciprocal L1 weight diagnostic, v618b

This frozen build adds a default-off reciprocal weight to the existing exact L1 cooperative diagnostic. This directory contains CPU/build evidence only. No GPU correctness or real-capture run is claimed here.

`--l1-prox --l1-weight NUMBER` selects a fixed positive weight. `--l1-prox --l1-weight cancel-global` chooses `omega=O/B` on the GPU after reduced scaling, once per solve. Both require the existing common-KKT option and an explicit positive cooperative grid. Omitting the weight retains the unit policy. No reference solution, pilot solve, adaptation or parameter sweep selects either weight.

The native-scaled base steps are `eta/omega` and `eta*omega`; original-coordinate steps are these bases times the existing primal and dual diagonal factors. The soft threshold is the actual original-coordinate primal step times original lambda. For `cancel-global`, the mathematical factors become `eta/D²` and `eta/R²`. Their product is unchanged. The same heuristic spectral estimate remains; it is not a proved norm bound. Original seed vectors, original common-KKT gates and original dual completion remain unchanged. Natural residual telemetry continues to use the legacy unweighted diagnostic.

The additive API preserves existing structure layouts. Changing policy restores iterate history, refreshes scaling and invalidates prior diagnostics; re-enabling L1 resets the policy to unit. Malformed or nonrepresentable weights reject; invalid effective diagonal steps or thresholds fail before any optimization update. Cancellation precedes initial qualification. Weight-record validity is separate from KKT qualification, and initial cancellation produces no valid weight record.
