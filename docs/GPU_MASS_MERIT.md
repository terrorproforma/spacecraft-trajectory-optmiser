# GPU minimum-mass merit

The v632 change makes the native SCvx outer controller account for the minimum-mass inequalities that its inner conic problem already enforces. It changes merit evaluation and the controller's feasibility screen; it does not change the fuel objective, cargo, schedule, conic constraints, or independent physical and fleet checks.

The measured v631 control return certified after two outer iterations. The candidate used the same archived ZOH trajectory with mass and thrust scaled together, but its retained physical seed ended at **1166.9174106318044 kg**, **10.289981565320886 kg** below the required **1177.2073921971253 kg**. Its 22 outer iterations accepted no step. The small dynamics defect, 2.13218e-13, did not make that seed mass-feasible. The candidate solve cost 9.093305 s; the complete two-case worker cost 10.787373 s. These are different scopes, and neither is a v632 timing result.

The frozen v631 source prices dynamics defects, endpoint constraints, initial mass, and free-Earth-vinf cone violations in the outer merit, but omits minimum mass. The inner conic assembly includes `mass[node] >= minimum_mass` at every node. Consequently an inner correction can pay virtual-control cost to satisfy the mass constraint while being compared with a reference whose mass violation has no price.

Saved arithmetic recovers reference fuel 0.189014597226556 and the existing endpoint penalty 0.000036001161486, giving an original merit of 0.189050598388042. At the unchanged virtual weight 10000 and conic deadband 1e-9, the missing terminal-only penalty is 71.513404473480. Including it raises the reference merit to 71.702455071868. The first qualified candidate's saved actual merit is 29.519427481447, so the corresponding actual reduction changes from -29.330376883059 to +42.183027590421. These are **dimensionless normalized subproblem costs**, not kilograms.

This is a counterfactual comparison of one saved candidate, not a rerun. Its dynamics defect and virtual infinity norm are both about 0.002803, so accepting that step would not establish convergence or certification. Its exact outer model was not retained: the saved QP objective gives a prediction/ratio proxy, not a recovered GPU measurement. Four reference nodes, 222–225, violate minimum mass; an all-node penalty is therefore required to match the original constraint family. Their total weighted hinge penalty is 178.331033922544.

For normalized state mass `m_i` and `mu = minimum_final_mass / initial_mass`, the new metrics are

```
mass_defect  = max_i max(mu - m_i, 0)
mass_penalty = sum_i max(mu - m_i - conic_tolerance, 0)
```

The existing device reduction visits every original mass row, including interior nodes and the final node. Nonfinite mass values mark the measurement invalid. Both the normal measurement and finer-propagation refresh retain the metrics. The controller adds `virtual_weight * mass_penalty` to reference merit, nonlinear candidate merit, and affine candidate model merit. The same hinge is appropriate in both candidate merits because the mass constraint is already affine in the original state variables. The conic objective and hard mass constraints remain unchanged.

Feasible/stationary acceptance and polishing confirmation additionally require `mass_defect <= defect_tolerance`, using the existing 5e-9 normalized controller threshold. The merit deadband remains the separate existing 1e-9 conic tolerance. These are not substitutes for the mission harness's much stricter final-mass test in kg, the physical leg certificate, or both original full-fleet checks. No existing threshold or gate is relaxed.

Implementation is confined to [the native SCvx controller](../cpp/cuda/src/gtoc12_scvx.cu), [its native tests](../cpp/cuda/tests/gtoc12_scvx_test.cu), and the internal reduction-call signature in [the device-refresh test](../cpp/cuda/tests/gtoc12_device_refresh_test.cu). The public C ABI is unchanged. The fresh build starts from committed v631 `cd8d6eb27f08f6966faaddac56e360b615a92256` with exactly those three CUDA overlays. Python and initializer arithmetic retain the measured v631 bytes.

Prepared regressions cover independent all-node hinge sums and maxima at 4, 37, 4097, and 10001 nodes; an interior deficit with a passing terminal mass; exact and adjacent representable deadband values; NaN and both infinities; disabled reduction/refresh preservation; consistent pricing in both candidate merits; and raw mass feasibility at and immediately above the existing controller threshold. They retain the prior endpoint, free-vinf, thrust, retry, and controller regressions. These tests exercise the controller independently of inner-solver convergence.
