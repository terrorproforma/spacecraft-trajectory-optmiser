This independent CPU fixture supports review of the pending opt-in mass/L1 native implementation on base `fdf52ae31d259240ffebdcf79ed0965dce8b9298`. It is an arithmetic/update oracle, not a convergence or physics benchmark. It changes no production files, loads no native library and launches no GPU work. Coefficients and starting vectors are synthetic, with no steps selected from known solutions. The committed v621 mass-structure and diagonal-metric reviews provide the two real-capture coefficient evidence and the preconditioning proof.

`oracle.py` produces `fixtures.json` using Python standard-library arithmetic. It contains the entire original dense coefficient layout, the reduced operator/right-hand sides, initial original x/scalar-dual/affine-dual vectors, direct diagonal steps, and three completed dual-first iterates in original coordinates. Original constraints use the existing native convention: the first six scalar rows are equalities, later scalar rows have lower bound minus infinity and the specified finite upper bound; the three affine rows form one SOC with radius last. All primal variables are free. Q is exactly zero.

The fixture has 15 original variables: four masses, three Gamma controls, three mass virtual controls, two other retained variables and three L1 epigraph variables. Its ordered node descriptors are `(mass,equality,Gamma,virtual) = (0,0,-1,-1), (1,1,4,7), (2,2,5,8), (3,3,6,9)`. The equations are `m0=1` and `m(k+1)-m(k)+g(k)*Gamma(k)-nu(k)=a(k)` with g = `[1/8,1/4,1/2]` and a = `[1/16,-1/32,1/64]`. The affine constants are `[1,1.0625,1.03125,1.046875]`; removing the nonzero a terms fails the exact map tests. Each node has three singleton scalar mass rows, including both coefficient signs. Additional retained equalities and scalar Gamma bounds exercise the untouched operator. The SOC row sums differ, so the shared denominator must actually lower some component steps.

Nine deterministic rational probes prove the original causal equations after reconstruction, exact original/reduced scalar slacks, the signed prefix/suffix adjoint, eliminated mass stationarity, the retained dual pullback and the dual objective constant sign. The reduced matrix is constructed independently by exact substitution. The fixture's norm certificate uses exact rational coefficient sums and inward-rounded FP64 steps. The expected upper bound is at most 0.9025. A GPU implementation using theta rounded down first and then directed division can produce steps one or two ULPs smaller than this oracle; that is acceptable. Compare native update vectors within a tight justified rounding allowance, and separately recompute the certificate from the *actual* stored GPU steps. Do not demand bitwise agreement with a different conservative division order or silently permit larger unsafe steps.

The agreed first implementation uses a linear forward operator and shifted bounds:

    d0 = 1; d(j+1) = d(j) + a(j)
    (S q)0 = 0; (S q)(j+1) = (S q)j + nu(j) - g(j)*Gamma(j)
    reduced mass-row upper = original upper - sign*d(j)
    forward mass-row value = sign*(S qbar)j
    exported mass = d(j) + (S q)j.

Constants must appear exactly once. The mathematically equivalent affine-forward/original-bound representation must not be mixed with this one. Floating prefix sums and shifted-bound subtraction are subject to rounding; the original-coordinate KKT audit remains the acceptance authority. The metric and adjoint use only the linear derivative, never d. The standalone coefficient proof does not automatically certify differently rounded GPU sums: use upward-rounded positive sums/products, shared SOC maxima and downward-rounded positive division, or another independently justified conservative construction. Guard zero/overflow/nonfinite coefficients, sums, steps and L1 thresholds. Constant operator rows use a positive dummy denominator but retain their constraints and original audit contribution.

For each dual-first step, update retained scalar duals using the interval Moreau map and SOC duals using one shared step for the entire block. Then compute the reduced objective/transpose gradient, apply direct per-variable steps and L1 soft thresholds, and extrapolate retained variables. Complete original mass values and equality multipliers before original epigraph pair multipliers. With w equal to the sum of retained original mass-row coefficient times multiplier (mass costs and mass SOC/equality uses are rejected in the initial scope), the recovered duals are `y_initial=-sum(w)` and `y_dynamic(j)=-sum(w[j:])`. These equality multipliers supply precisely `S^T w` to the retained original gradient. The oracle verifies that this full original gradient matches the reduced gradient used by the proximal step.

The three update records exercise positive, exactly zero and negative virtual controls simultaneously. They are deliberately unqualified finite iterates, so a native test should require matching arithmetic/counts and unchanged original gates, not OPTIMAL status. A separate zero-step fixture has only positive epigraph objective coefficients. Its original supplied point includes `nu0=t0=1e-20` with interior epigraph multipliers, and passes all common gates. Reconstructing endpoint multipliers merely because the represented nu0 is positive creates normalized stationarity 0.05 and fails. Therefore a qualified original supplied point must be checked unchanged before any reduced primal/dual completion. Its bitwise x/dual identity is a stronger lifecycle test than numerical tolerance.

The fixture's original gate evaluation uses exact rational sparse products of the represented FP64 vectors, FP64-represented reconstructed slack and FP64 SOC norms. It preserves separate equality and combined nonnegative/SOC transpose groups for stationarity normalization, original objective/support terms, equation residuals, primal/dual cone defects, global gap and per-block complementarity. The normalized tolerance remains 1e-9 and cone tolerance 1e-8. These checks supplement the existing independent snapshot auditor; they do not replace the latter with a transformed-problem certificate.

Before native launch, source review and the implementation's CPU tests should additionally cover the following runtime contracts, which this arithmetic-only script cannot establish:

- Descriptor indices, node order, finite positive g, exact causal ±1 coefficients and finite right-hand sides; globally distinct active mass/control roles; no overlap with removed epigraph variables or pair rows; exactly the supported singleton retained mass uses. Structural zeros do not create an extra mathematical use, but a tiny nonzero coefficient does.
- Initial common qualification and cancellation precede any mutation of original x/dual. A cancellation during initialization must not advertise stale valid metric/iteration records. An unqualified point may be reconstructed only as part of the explicitly counted reduced solve lifecycle.
- Original matrix/objective/bounds remain available to common KKT; working masks, shifted bounds, scan scratch, steps and history are separate. Disable/re-enable, reseed and default-mode comparison force correct scaling/history refresh. Reject coefficient updates, incompatible weights, Halpern or checkpoint operations while enabled under the agreed bounded API scope.
- Query occupancy for the new cooperative kernel, constrain explicit block counts to that capacity, size scratch safely, and keep old default/common/unit-L1/weighted-L1 kernel resource footprints isolated. No change to the original stopping gates, no hidden recovery and no default promotion.
